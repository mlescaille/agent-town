# @agentlicense/core

Types and checks for [Agent License](https://github.com/mlescaille/agent-town): Ed25519 JWS licenses, the three mandate types, delegation, attenuation, and the Merkle decision log.

```sh
npm install @agentlicense/core
```

The package is not on the npm registry yet. Until it is published, install from a clone of the repository and import the workspace package. See the [SDK reference](https://github.com/mlescaille/agent-town/blob/main/docs/sdk.md).

Node.js 22 or newer. This package is ESM only.
