Three mandates

direct_request:

the user asked for this exact action

user_goal:

the user set the goal, the agent picks the steps

agent_initiated:

the agent acts on its own, read-only by default

Sub-agents say who they are

“I am Researcher (subagent-123), acting on behalf of Planner (planner-1), on behalf of user:alice, requesting documents.search.”

Quickstart

git clone https://github.com/mlescaille/agent-town.git
cd agent-town && pnpm i && pnpm build
pnpm exec agentlicense keys init
pnpm exec agentlicense issue \
  --user alice \
  --agent planner \
  --mandate user_goal \
  --goal "Summarize the primary calendar" \
  --actions calendar.read,calendar.create \
  --locations calendar:primary \
  --budget 10 \
  --ttl 3600 > license.jwt
pnpm exec agentlicense check \
  --license "$(cat license.jwt)" \
  --action calendar.read \
  --location calendar:primary \
  --why "Reading today's events is how the summary gets its facts."
